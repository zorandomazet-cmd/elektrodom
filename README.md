# ElektroDom – V1

Testna spletna stran za razvoj AI prodajnih in servisnih botov.

## Lokalni test
Odpri `index.html` v brskalniku. Za osnovni V1 ne potrebuješ strežnika.

## Cloudflare Pages
- Production branch: `main`
- Build command: `exit 0` (ali pusti prazno, če nadzorna plošča to omogoča)
- Build output directory: `/` oziroma root projekta
- `index.html` mora biti v korenu repozitorija.

## Pomembno
Vsi izdelki, cene in storitve so demonstracijski. V1 ne izvaja dejanskih nakupov in podatkov obrazca ne pošilja na strežnik.

Naslednje faze:
1. pravi AI API
2. baza leadov
3. e-mail/CRM
4. AI kvalifikacija
5. analitika
6. checkout
7. varnost, GDPR in produkcijska vsebina
